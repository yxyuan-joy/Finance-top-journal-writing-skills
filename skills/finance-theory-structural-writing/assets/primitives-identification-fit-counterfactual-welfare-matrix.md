## 8. Drafting handoff

Use the completed matrix to write:

- **Mechanism sentence:** [primitive/friction + incentive + equilibrium response]
- **Formal-result sentence:** [result type + exact domain + benchmark difference]
- **Discipline sentence:** [identified/calibrated/fixed inputs + data variation/moments]
- **Fit sentence:** [targeted fit separated from untargeted/holdout validation]
- **Counterfactual sentence:** [policy change + magnitude + invariance/closure qualifier]
- **Welfare sentence:** [criterion + winners/losers + externality + sensitivity]
- **Boundary sentence:** [most important untested assumption, miss, or extrapolation]

Final gate: the manuscript must not jump directly from a plausible primitive to a welfare result. The path through mechanism, result, discipline, policy-relevant fit, counterfactual closure, and welfare accounting must be complete wherever each link is claimed.
