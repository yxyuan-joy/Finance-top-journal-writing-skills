# Theory–Empirics Interface

## Evidence roles

| Role | Function | Allowed claim |
|---|---|---|
| Motivating fact | Establishes puzzle | motivates model |
| Targeted moment | Disciplines parameter/model | model matches by construction/estimation |
| Identifying variation | Separates parameter/object | identifies conditional on model |
| Untargeted moment | External restriction | supports model on this margin |
| Qualitative prediction | Tests sign/ranking | consistent/inconsistent with mechanism |
| Quantitative prediction | Tests magnitude/distribution | fit on stated margin |
| Counterfactual | Model-implied scenario | conditional implication |

## Discriminating tests

A useful model test identifies a prediction that differs from a credible benchmark or alternative mechanism. State:

1. Which assumption/friction generates the prediction.
2. What the alternative predicts.
3. How the observable maps to the model object.
4. Whether the test was targeted in estimation.
5. What rejection/non-rejection means for the model component.

## Common overclaims

- Matching a calibration target does not validate the model.
- A reduced-form correlation consistent with the model does not identify its mechanism.
- A parameter estimate precise under the model does not eliminate model misspecification.
- An untargeted moment selected after seeing results is weaker than genuine holdout validation.
- A successful counterfactual decomposition is not a causal experiment unless the maintained structure is credible.
