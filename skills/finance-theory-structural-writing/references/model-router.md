# Theory and Structural Model Router

## Pure theory

Primary contribution: a mechanism, characterization, comparative static, impossibility, contract, market design, or welfare result.

Required narrative:

```text
economic puzzle
→ minimal environment
→ friction/information/constraint
→ equilibrium mechanism
→ proposition and intuition
→ comparative static / empirical prediction / welfare implication
→ boundary
```

## Quantitative/calibrated model

Primary contribution: quantitative importance or equilibrium decomposition. State parameter sources, calibrated targets, benchmark fit, non-targeted validation, counterfactual, and sensitivity. Do not call a parameter “identified” solely because it is chosen to match a moment.

## Structural estimation

Primary contribution: estimates primitives or latent objects and uses them for decomposition/counterfactuals. Map data variation/moments to parameters; explain normalizations, estimation, uncertainty, fit, and counterfactual closure.

## Theory–empirics hybrid

Primary contribution may be mechanism plus discriminating tests. State which predictions differ from alternatives, which tests are reduced-form, and which model features remain untested.

## When to pair skills

- Pair with `$finance-asset-pricing-writing` for equilibrium asset-pricing models with central portfolio/SDF tests.
- Pair with `$finance-intermediation-markets-writing` for bank/dealer/market-design mechanisms.
- Pair with `$finance-causal-empirical-writing` only when exogenous variation independently identifies a model prediction or parameter channel.

Keep one primary contribution and explain the role of the other component.
