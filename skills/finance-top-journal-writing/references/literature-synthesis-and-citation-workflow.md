# Literature Synthesis and Citation Workflow

Read this reference when the task is to build or repair a literature section, organize research streams, compare the closest papers, or verify citation support. Do not load it for a narrow paragraph edit whose citations and positioning are already settled.

## Build a claim-to-source ledger first

For every citation-dependent sentence, record:

| Field | Entry |
|---|---|
| Manuscript claim | The exact proposition the citation must support |
| Role | Fact, method precedent, theoretical mechanism, empirical finding, boundary, or contrast |
| Source status | Verified full text, verified abstract/metadata only, author-supplied but unchecked, or missing |
| Scope | Population, market, period, outcome, design/model, and direction |
| Match | Direct support, partial support, adjacent only, or contradiction |
| Safe sentence | Wording no stronger than the verified source |

Never invent a source, DOI, author, date, result, or page. If the user has not supplied verified references and current search is unavailable or outside scope, use `[CITATION NEEDED]` and state what evidence the source must contain.

## Map the literature by economic function

Group papers by the question or evidence role they perform, not by a sequence of author names. A useful map contains three to five streams:

1. the closest papers asking the same economic question;
2. papers sharing the proposed mechanism but studying another margin;
3. papers sharing the design, measurement, or model discipline;
4. papers establishing the institutional or empirical fact the paper builds on;
5. a live competing explanation, when it changes interpretation.

For each stream, write one synthesis sentence that states the shared object and one contrast sentence that identifies within-stream disagreement or variation. Do not pretend a stream is homogeneous when samples, estimands, horizons, constructs, or equilibrium closures differ.

## Compare the nearest papers symmetrically

Use the same fields for the focal paper and each nearest comparator:

| Comparison field | Question to answer |
|---|---|
| Economic question | Is the outcome, decision, or welfare object the same? |
| Population/setting | Does the paper study the same agents and institutional regime? |
| Evidence logic | Descriptive, predictive, causal, model-based, or counterfactual? |
| Key construct | Is the treatment, signal, mechanism, or parameter measured the same way? |
| Result | What direction, magnitude, and boundary are actually established? |
| Increment | What does the focal paper change that the comparator could not answer? |

Write the contribution as an exact changed margin: a new estimand, a different population that tests transportability, direct measurement of a previously inferred mechanism, independent validation, model discipline, equilibrium response, or welfare accounting. `New data`, `new setting`, and `first study` are not sufficient without explaining what becomes learnable.

## Choose placement

Default to concise positioning inside the introduction when the literature's only job is to define the gap and contribution. Use a standalone section only when readers need a taxonomy, several mechanisms must be reconciled, definitions differ across streams, or later hypotheses/model choices depend on the synthesis. Do not repeat the same contribution list in both locations.

A standalone section can follow:

```text
economic object and scope
→ stream 1: established result and unresolved margin
→ stream 2: alternative mechanism or evidence logic
→ stream 3: method/model/measurement frontier
→ closest-paper comparison
→ precise handoff to this paper's design or model
```

## Draft paragraphs as synthesis

Each paragraph should contain:

1. a stream-level claim;
2. representative evidence, with verified citations;
3. meaningful differences or disagreement;
4. the unresolved margin relevant to this paper;
5. a transition to the next stream or the focal contribution.

Avoid one-sentence-per-paper summaries, chronological tours, prestige lists, and citation piles attached to a claim none of the sources directly supports. Do not cite a review as if it were the underlying empirical evidence when the original study is needed for a precise result.

## Verify before delivery

Check every citation-dependent clause against the strongest source actually inspected. Distinguish metadata/abstract verification from full-text verification. Confirm names, years, titles, DOI or stable link when included, and whether the source supports the stated direction, population, design, and boundary. Keep disagreements visible instead of averaging them into a false consensus.

Final gate: the section should make the paper's nearest conversation and exact increment clear even if all author names are temporarily hidden. If removing the citations leaves only a list of topics, rebuild the synthesis around economic claims and comparisons.
